# ระบบรายงานวิเคราะห์ข้อมูลลานจอดรถ 2026 (Interactive Dashboard)

หน้าเว็บ Dashboard แบบไดนามิกสำหรับวิเคราะห์ข้อมูลลานจอดรถ (ลาน 2 ความจุ 346 คัน และ ลาน 3 ความจุ 82 คัน)

## โครงสร้างไฟล์
- `index.html` — หน้าเว็บ Dashboard แบบโต้ตอบ (กรองเดือน / ลานจอดรถ / ปรับความจุสด / นำเข้าไฟล์ `.xls` ใหม่ได้)
- `dashboard_data.json` — ข้อมูลสรุปรายวันและรายชั่วโมง (**ไม่มีข้อมูลเลขทะเบียนรถหรือข้อมูลส่วนบุคคล**)

## การอัปเดตข้อมูลเดือนใหม่
1. วางโฟลเดอร์ไฟล์ `.xls` เดือนใหม่ใน `D:\parking-data-report\raw_data\ข้อมูลรถยนต์\` (เช่น `12`)
2. ดับเบิลคลิกไฟล์ `D:\parking-data-report\update_and_publish.bat` เพื่อคำนวณใหม่และอัปเดตขึ้นเว็บอัตโนมัติ

## การย้ายระบบในอนาคต (Private / Internal)
สามารถย้ายโฟลเดอร์นี้ไปวางบน **Firebase Hosting**, **Google Cloud Storage**, หรือ **Web Server ภายในองค์กร** (พร้อมระบบ Login + BigQuery) ได้ทันทีโดยไม่ต้องเขียนหน้าเว็บใหม่
