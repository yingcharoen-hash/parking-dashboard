ใส่รหัส GitHub Token เพียงครั้งแรกครั้งเดียว (ระบบจะจำไว้ในเบราว์เซอร์เครื่องแอดมินเท่านั้น ไม่ถูกส่งไปที่อื่น) จากนั้นวันต่อไปแค่ลากไฟล์แล้วกดปุ่มเขียวได้เลยครับ
วิธีสร้าง GitHub Token ให้แอดมิน (ทำครั้งเดียวใช้ได้ตลอด): เข้า GitHub → มุมขวาบนรูปโปรไฟล์ → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → เลือก Repository access เฉพาะ parking-dashboard → Permissions ตรง Contents เลือก Read and write → กด Generate แล้วคัดลอกรหัสมามอบให้แอดมินใส่ในช่องด้านบนครับ
